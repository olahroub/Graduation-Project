# تطبيق بيتيات - Baytiyat Flutter App

تطبيق موبايل متكامل تم تطويره كـ **مشروع تخرج** باستخدام إطار العمل **Flutter** ولغة **Dart**، يهدف إلى ربط أصحاب المشاريع المنزلية والأسر المنتجة (Vendors) بالمستهلكين بشكل مباشر وسلس.

An integrated mobile application developed as a **Graduation Project** using **Flutter** and **Dart**. It aims to connect home-based businesses/productive families (Vendors) directly with consumers.

## المميزات الأساسية | Key Features
* **نظام مستخدمين مزدوج (Dual User System):** واجهات مخصصة للمشترين (Users) وواجهات مستقلة لإدارة المتاجر من قِبل البائعين (Vendors).
* **إدارة المنتجات:** إمكانية إضافة، تعديل، وعرض المنتجات وتفاصيلها بشكل جذاب.
* **إدارة الحسابات:** نظام تسجيل مستخدم جديد (Register) وتسجيل الدخول (Login) وحفظ بيانات ملف التعريف الشخصي (Profile).
* **تصميم مرن (UI/UX):** استخدام عناصر مخصصة (Custom Widgets) لضمان تجربة مستخدم سريعة ومتناسقة.

## التقنيات المستخدمة | Technologies Used
* **Framework:** Flutter
* **Language:** Dart
* **State Management & Utils:** Shared Preferences / Custom Widgets
